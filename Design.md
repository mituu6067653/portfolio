# Meet Bhandari Portfolio — Design System

## 1. Design Direction
**Editorial + Modern Product Design**

The portfolio should feel:
- Personal
- Premium
- Modern
- Technical
- Confident
- Human

It must not look like a generic developer template or AI-generated landing page.

## 2. Color System
Primary text: `#0F172A`  
Secondary text: `#475569`  
Background: `#F8FAFC`  
Surface: `#FFFFFF`  
Border: `#E2E8F0`  
Accent: `#2563EB`  
Accent hover: `#1D4ED8`  
Success: `#16A34A`

Use accent selectively. Avoid turning the entire website into a blue dashboard.

## 3. Typography
Primary: **Inter**

Alternative: Manrope/system sans-serif.

Desktop:
- Hero: 48–72px
- Section heading: 32–44px
- Card heading: 18–22px
- Body: 16–18px
- Small text: 13–14px

Mobile should scale naturally.

## 4. Navbar
Desktop:
- Meet Bhandari / wordmark
- Work
- Services
- About
- Contact
- Small CTA

Mobile:
- Name
- Menu
- Contact CTA where practical

## 5. Hero
Left-aligned, typography-led composition.

Use:
- Meet Bhandari
- Full-Stack Web Developer
- Direct positioning statement
- Supporting copy
- Two CTAs
- One small personal detail

Do not use a giant stock laptop image.

## 6. Personal Touch
Use one honest human detail such as:
- Based in India
- Currently building & shipping
- Available for selected freelance projects

Do not fabricate availability.

## 7. Featured Work
This is the most important visual section.

Use actual screenshots of:
1. ServiceFlow
2. PropertyFlow CRM
3. Manufacturing Business Management System

Each card should have:
- Screenshot
- Name
- Short explanation
- Category
- Technologies
- Live Demo

## 8. Project Detail
Recommended:
- Hero screenshot
- Problem
- What was built
- Workflow
- Features
- Technology
- Important decisions/challenges
- Live Demo

Clients should understand value before technical depth.

## 9. Services
Four clear service cards:
- Business Websites
- Custom Web Applications
- Website Redesign
- Bug Fixes & Improvements

Avoid generic agency language.

## 10. Process
Desktop:
**01 Understand → 02 Plan → 03 Build → 04 Launch**

Mobile: stack vertically.

## 11. About
Split layout:
- Personal/professional introduction
- Technology list

Use a real photograph only if Meet wants one.

Do not use an AI-generated portrait as a real personal photo.

## 12. Tech Stack
Group by:
- Frontend
- Backend
- Database
- Workflow/Deployment

Do not create a wall of logos.

## 13. Contact
Large heading:
> Have a project in mind?

Supporting copy:
> Tell me what you're building. I'll get back to you with the next steps.

Simple form + direct contact option.

## 14. Footer
Keep it small:
- Meet Bhandari
- Full-Stack Web Developer
- GitHub
- LinkedIn
- Email
- Copyright

## 15. Motion
Good:
- Short section reveal
- Card hover
- Button transition
- Subtle image scale

Avoid:
- Cursor-following everywhere
- Floating blobs
- Endless marquees
- Excessive 3D
- Long loading animations

## 16. AI-Feel Prevention
Avoid:
- “Building the future...”
- “Transformative digital experiences”
- Purple/blue glowing backgrounds
- Giant meaningless statistics
- Fake testimonials
- Fake client logos
- Excessive gradients
- Too many rounded cards
- Buzzword-heavy copy

Instead:
- Use direct language
- Show real work
- Use actual screenshots
- Explain real workflows
- Keep whitespace intentional
- Add small personal details

## 17. Brand Personality
**Quiet confidence.**

Not:
> I am the world's best developer.

Instead:
> Here is what I built. Here is how it works. If you need something similar, let's talk.
