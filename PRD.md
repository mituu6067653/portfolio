# Meet Bhandari — Freelance Portfolio PRD

## 1. Product
A personal portfolio and client-acquisition website for **Meet Bhandari**, positioned as a Full-Stack Web Developer.

**Goal:** turn genuine visitors into freelance inquiries.

The site must feel personal, confident and human — never like an AI-generated template or agency website.

## 2. Audience
- Small/local business owners
- Startup founders
- Clients needing business websites
- Clients needing custom web applications
- Recruiters and developers as secondary visitors

Client needs take priority over recruiter-oriented presentation.

## 3. Profile
**Name:** Meet Bhandari  
**Role:** Full-Stack Web Developer  
**Location:** India  
**Education:** B.Voc. Software Development, 5th semester

Relevant technologies:
HTML, CSS, JavaScript, TypeScript, React, Next.js, Node.js, PostgreSQL, Prisma, Git/GitHub, Vercel.

Only claim technologies that are genuinely comfortable to use.

## 4. Positioning
Primary message:

> I build modern websites and custom web applications for businesses.

Supporting message:

> From responsive business websites to complete dashboards and workflow-based systems, I build products that are made to actually work.

Avoid exaggerated claims and buzzwords.

## 5. Services
### Business Websites
Responsive websites for businesses and professionals.

### Custom Web Applications
Dashboards, management systems, CRMs and workflow-based applications.

### Website Redesign
Modernize outdated websites and improve mobile usability.

### Bug Fixes & Improvements
Fix existing frontend/backend problems and improve applications.

## 7. Project Cards
Each featured project should show:
- Name
- Category
- Short explanation
- Problem/need
- 3–5 key features
- Technologies
- Live Demo
- GitHub only when intentionally public

Never invent client results or pretend demo projects are paid client work.

## 8. Homepage
Recommended order:
1. Navigation
2. Hero
3. Proof
4. Featured Work
5. Services
6. How I Work
7. About
8. Tech Stack
9. Contact CTA
10. Footer

## 9. Hero
Suggested copy:

**Meet Bhandari**  
**Full-Stack Web Developer**

> I build modern websites and custom web applications for businesses.

Buttons:
- View My Work
- Start a Project

Optional honest detail:
- Based in India
- Available for selected freelance projects
- Currently building & shipping

## 10. Proof
Use only verifiable proof:
- Live deployed projects
- Full-stack applications
- Business workflow systems
- Project count if accurate

Never invent clients, revenue, years of experience, testimonials or conversion numbers.

## 11. Services
Services should describe client outcomes rather than only listing technologies.

## 12. Process
**01 Understand → 02 Plan → 03 Build → 04 Launch**

Keep it practical.

## 13. About
Briefly explain:
- Who Meet is
- B.Voc. Software Development
- Full-stack focus
- Real projects
- Interest in business-focused applications

Do not turn the About section into an autobiography.

## 14. Contact
Simple inquiry form:
- Name
- Email
- Project type
- Message

Optional:
- Budget
- Timeline

CTA:
> Have a project in mind? Let's talk.

## 15. Responsive
Must work on desktop, tablet and mobile.

## 16. SEO
Include:
- Useful title
- Meta description
- Open Graph metadata
- Semantic headings
- Favicon
- Sitemap/robots where useful

## 17. Non-Goals
Do not build:
- Blog CMS
- Client portal
- Fake testimonials
- Fake client logos
- Fake reviews
- AI chatbot
- Unnecessary 3D experience
- Excessive animation
- Unnecessary admin system

## 18. Success Criteria
Within roughly 30 seconds a visitor should understand:
- Who Meet is
- What he builds
- What he has built
- How to contact him

The website exists to start real conversations, not merely display skills.
